# Among Us Shooter

Dynamiczna gra strzelankowa 2D stworzona w silniku **Godot Engine 4.x** (Forward+ / D3D12).

## Sterowanie

| Akcja                   | Klawisz / Sterowanie                      |
| :---------------------- | :---------------------------------------- |
| **Ruch**                | `W`, `S`, `A`, `D`                        |
| **Strzał (kierunkowy)** | Strzałki (`Góra`, `Dół`, `Lewo`, `Prawo`) |
| **Strzał alternatywny** | `Spacja`                                  |

## Wymagania i uruchomienie

1. Zainstaluj **Godot Engine 4.3+** (Standard lub .NET).
2. Sklonuj repozytorium na dysk.
3. W Godot Project Manager kliknij **Import** i wskaż plik `project.godot`.
4. Uruchom grę za pomocą klawisza **F5** (Run Project).

## Struktura projektu

Standardowa podzielona na:

- `assets/`
- `scenes/`
- `scripts/`
